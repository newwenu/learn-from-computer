# 学生可用的资源

> 阅读前提：建议先阅读开篇的「大学里的数字基础设施」一节，了解"资源"在大学数字体系中的位置。

上一节讲了校园网和统一身份认证——它们是大学数字基础设施的地基。这一节讲的是通道尽头的"房间"：学校为师生提供的各种数字化资源。

这些资源通常由学校集中采购或搭建，师生可以免费或以优惠价格使用。

## 学校邮箱

### 这是什么

学校邮箱是学校通常为师生分配的、以学校域名为后缀的邮箱账户。比如 `yourname@school.edu.cn`。它不仅是收发邮件的工具，也是你作为本校学生的数字化身份证明。

### 为什么需要它

学校邮箱不只是收发邮件的工具——你日常可能更常用 QQ 邮箱或 Gmail。它的一个重要价值在于：**是很多外部服务验证"你是本校学生"的凭证**。很多商业软件、云服务、优惠活动需要你用学校邮箱注册或验证，以此来确认你的学生身份。

### 你需要了解的

- **怎么激活**：不同学校的激活方式不同，有的在入学时已自动开通，有的需要到学校的邮箱服务页面手动激活。学校 IT 部门网站或迎新材料里通常会有说明。
- **学校邮箱地址**：了解你的学校邮箱地址格式，尤其是域名部分（@后面的内容），这是判断学生身份的关键。
- **存储空间**：有的学校邮箱存储空间有限，不要把它当作主要的文件存储工具。
- **不要绑定重要个人账号**：学校邮箱可能会在你离校后一段时间被关闭。建议不要把社交账号、网购账号、云存储等重要个人服务绑定到学校邮箱，或者在绑定后留意改绑方式。

### 常见问题

**学校邮箱收不到邮件**

- 检查邮箱是否已激活。
- 查看垃圾邮件文件夹，学校系统发出的邮件有时会被误判为垃圾邮件。
- 设置学校邮箱自动转发到你常用的邮箱（如 QQ 邮箱、Gmail），这样学校的邮件会自动出现在你常看的邮箱里。转发设置通常在学校邮箱的设置页面里。

**学校邮箱能用什么**

- 申请各种商业软件的学生版或教育版。
- 接收学校官方的正式通知。
- 注册学术数据库、科研平台等外部服务。
- 具体能用哪些服务，取决于学校和外部机构的合作情况，以学校 IT 部门的说明为准。

## 校园正版软件

### 这是什么

学校可能集中采购了某些软件的校园授权（也叫"教育版"或"校园版"），师生可以下载安装并使用，比个人购买便宜很多，通常也是正版。

### 为什么学校要提供

软件授权费用不低，如果每个师生自己购买，成本会很高。学校集中采购后统一分配给师生使用，可以降低成本，同时也能保证软件的合规性（避免使用破解版带来的安全和法律风险）。

### 常见的几种模式

- **直接免费使用**：部分学校购买了某些软件的不限用户数授权，师生可以自由下载使用。
- **按学院/专业授权**：部分软件只授权给特定学院或专业的师生使用，需要通过学院申请。
- **数量有限**：部分软件有并发用户数限制，下载前可能需要先确认是否还有可用名额。

### 你需要了解的

- **下载入口**：正版软件的下载入口通常在学校 IT 部门网站的"软件下载""正版服务"等栏目下。
- **是否需要认证**：有的软件需要登录统一身份认证后才能下载，有的需要填写申请表。
- **保存安装包**：下载安装包后建议保存一份，换电脑时可以直接安装，不用重新下载。
- **使用期限**：部分校园软件的授权在毕业后会失效，重要项目尽量不要依赖校园授权的软件。

### 常见问题

**找不到软件下载入口**

- 搜索"学校名 + 软件下载/正版服务/IT服务中心"。
- 问辅导员或学长学姐："学校有没有提供 XX 软件的下载？"
- 不同学校的入口位置差异较大，以学校 IT 部门网站的实际布局为准。

**软件装不上**

- 确认你的设备是否在学校授权范围内（部分软件需要连接校园网或登录统一身份认证后才能下载或激活）。
- 检查系统兼容性——确认软件支持你的操作系统和版本。
- 如果是网络授权的软件，需要先连校园网或校外访问。
- 实在装不上可以联系 IT 部门的技术支持。

## 学生优惠

### 这是什么

很多商业软件和服务对学生提供折扣或免费版本，通常需要用学校邮箱验证学生身份才能申请。

### 和校园正版的区别

校园正版是学校统一采购的，在校师生通常都能用；学生优惠是软件厂商直接给学生的折扣，需要你自己去申请。两者可能有重叠——有的软件既是校园正版，也有独立的学生优惠。如果两者都有，优先用校园正版——通常更方便，不需要自己申请。

### 常见的几种模式

- **免费**：部分软件对在校学生不收取费用。
- **折扣**：部分软件对学生提供优惠价格。
- **功能受限的免费版**：部分软件提供学生免费版，但功能可能比付费版少。

### 你需要了解的

- **怎么申请**：通常在软件官网的"学生版/教育版"页面申请，用学校邮箱注册或验证即可。
- **时效性**：学生优惠通常和学籍绑定，毕业后可能需要重新验证或会失效。
- **以官网为准**：学生优惠的政策经常变化，具体以软件官网的最新说明为准。

## 学校 IT 支持服务

### 这是什么

学校 IT 部门除了管理网络和账号，有时还会提供一些面向师生的服务。

### 常见的几种服务

- **电脑维修**：部分学校 IT 部门提供免费或收费的电脑硬件维修服务。
- **网络配置**：如果你的设备连不上校园网，可以找 IT 部门协助排查。
- **云存储空间**：部分学校为师生提供云存储空间（如 Microsoft OneDrive 教育版、学校自建网盘等），可以用来存储和备份文件。
- **系统安装镜像**：部分学校提供正版系统的安装镜像下载。

### 你需要了解的

- **服务范围**：不是所有学校都提供以上所有服务，具体要看学校 IT 部门的说明。
- **服务窗口**：IT 部门的线下服务时间和地点，线上报修入口在哪里。
- **响应时间**：有些 IT 部门只在工作时间提供服务，响应可能需要一些时间。

## 你的行动项

1. **激活学校邮箱**——如果你还没激活，尽早去学校的邮箱服务页面完成激活，并设置自动转发到你常用的邮箱。
2. **查看学校提供的正版软件列表**——登录 IT 部门网站，看看学校为师生提供了哪些正版软件。
3. **用学校邮箱申请常用软件的学生优惠**——如果你需要使用某些软件，可以先查一下是否有学生优惠。
4. **了解 IT 部门的服务范围**——知道学校 IT 部门提供哪些服务，以及怎么联系他们。
5. **避免把重要个人账号绑定到学校邮箱**——如果已经绑定，留意改绑方式，避免离校后无法接收验证码。

如果在激活邮箱、下载软件或申请学生优惠时遇到看不懂的选项，先停下来，问辅导员、学长学姐或 IT 部门，不要急着提交。
