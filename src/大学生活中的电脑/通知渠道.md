# 通知渠道

> 阅读前提：建议先阅读[《开篇：大学里的数字世界》](./开篇：大学里的数字世界.md)中“入学后要搞清楚的几件事”一节，了解通知渠道的整体概念。

大学里的通知来源很多——课程通知、学院通知、学校通知、活动通知、缴费提醒……它们分散在不同的平台里。如果你只看一个渠道，很容易漏掉重要信息。这一节讲怎么把这些渠道都串起来。

## 这是什么

通知渠道就是学校和老师向你发送信息的各种平台。大学里通知的来源很多，即使学校有统一的通知平台，也很难把所有通知都收在一个地方——你需要在多个渠道之间切换，搞清楚每种通知主要在哪个渠道看。

## 为什么通知不统一

这看起来很不方便，但背后的原因很实际：

- **不同部门用不同工具**：教务处、学工部、学院、后勤……每个部门根据自己的习惯和需求选择通知方式，没有统一规定。
- **历史原因**：有些系统用了很多年，更换成本高。企业微信和钉钉的普及让情况在改善，但各校进度不同。
- **信息重要性不同**：紧急通知（如停水停电、考试安排）需要强提醒，普通通知（如活动预告）只需要触达即可。不同渠道的推送方式不一样。

## 常见的通知渠道

不同学校使用的渠道不同——你的学校可能只用到其中一部分，也可能还有其他渠道。以下是大学里最常见的几种，你需要搞清楚自己学校主要用哪些：

### 班级微信群 / QQ 群

这是辅导员和班委发布通知的主要渠道。日常通知、班会安排、活动信息大多会在这里发。

注意：群消息容易被刷走，重要通知要及时标记或截图保存。群里的信息不一定经过官方核实，涉及缴费、链接等要注意甄别。

### 企业微信 / 钉钉

很多学校（但不是全部）用企业微信或钉钉作为官方通知渠道。相比微信群，它们支持已读回执（发送者能看到你有没有读过这条消息）、审批流程、身份认证等功能，适合正式的通知和事务管理。

如果你的学校用了企业微信或钉钉：

- 企业微信通常可以和个人微信绑定，绑定后学校通知可能会同步推送到微信，具体要看学校的设置。
- 钉钉的通知是独立的，记得打开钉钉的通知权限，不然可能错过重要消息。
- 通常需要加入学校的组织才能收到通知，学校会发送邀请链接或二维码。

### 课程平台

老师在超星学习通、雨课堂、学堂在线等平台上发布课程相关通知：作业要求、课堂内容、考试安排等。

不同课程可能用不同平台——开学初要搞清楚每门课用的是哪个平台。平台上的通知通常和课程绑定，漏掉了可能错过作业提交、考试安排等重要信息。

### 学校 / 学院公众号

学校官方公众号发布重要通知、活动信息、政策变化等。学院公众号会发布学院特有的通知，如学术讲座、竞赛信息、评优通知等。

### 教务系统

选课、成绩、考试安排、培养方案等与学业直接相关的信息，通常只在教务系统发布。这些信息一般不会通过微信群等其他渠道同步。

定期登录教务系统查看——有些通知不会通过其他渠道同步发送。

### 学校邮箱

部分正式通知（如学校公文、缴费通知、重要提醒）会通过学校邮箱发送。相比群消息，邮件更正式、更可追溯。

## 你可能会遇到的问题

### 漏掉重要通知

最常见的情况是：某个渠道的通知你没设置提醒，或者设置了但被系统静音了。

- **系统层面检查**：如果你学校用了企业微信、钉钉或课程平台应用，确保它们的通知权限已打开。
- **定期主动查**：教务系统和学校邮箱不要只等推送，养成每天或每两天主动查看的习惯。
- **关键节点多渠道确认**：选课、考试、缴费等关键事项，通过多个渠道交叉确认，避免单一渠道遗漏。

### 群消息被刷走

班级群消息量大，重要通知可能很快被刷到下面。

- 用微信的“置顶聊天”功能让重要消息保持在列表顶部。
- 或用“标为未读”功能给自己留个提醒。
- 看到重要通知时，随手截图保存到手机相册或收藏夹。

### 企业微信 / 钉钉收不到通知

如果学校用了企业微信或钉钉但你收不到通知，常见原因：

- 没有加入学校的组织——需要通过学校发送的邀请链接或二维码加入。
- 通知权限没开——手机系统设置里检查是否给了应用通知权限。
- 版本太旧——更新到最新版本。

### 学校邮箱不常看

学校邮箱不是日常通讯工具，很容易被忽略。但有些正式通知只发邮箱，不会在群里同步。

一个实用的办法：**把学校邮箱设置自动转发到你常用的邮箱**（如 QQ 邮箱、Gmail）。这样学校的邮件会自动出现在你常用的邮箱里，不会漏掉。设置方式通常在学校邮箱的设置页面里。

## 你的行动项

入学后，你可以尽早：

1. **搞清楚学校主要用哪些通知渠道**——问辅导员或学长学姐：“学校通知主要在哪看？”了解你们学校用的是企业微信、钉钉，还是其他平台。
2. **加入所有班级和课程的微信群 / QQ 群**，并打开群消息通知。
3. **登录教务系统和学校邮箱**，确认能正常访问。
4. **如果学校有企业微信或钉钉**，按要求加入组织，打开通知权限。
5. **如果学校有公众号**，关注学校和学院的官方公众号。
6. **把学校邮箱设置自动转发**到你常用的邮箱。
7. **在课程平台上注册 / 加入每门课的班级**，确保能收到课程通知。

养成习惯：每天花 5 分钟查看一遍各个渠道的通知，比漏掉重要消息后再补救要高效。
