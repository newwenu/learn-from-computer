# 校外访问校内资源

> 阅读前提：建议先阅读开篇的「大学里的数字基础设施」一节，了解校内和校外网络的差异。如需了解更多网络基础知识，可参考[《理解你的网络》](../主要内容/理解你的网络.md)。

上一节讲了学校为你提供了哪些资源：图书馆数据库、正版软件、学生优惠等。但这些资源很多只在校园网内才能访问——你在宿舍用校园网能打开的数据库，回到家用家里的宽带可能就打不开了。

这不是坏了，而是一种基于网络位置的权限控制。校外访问就是解决这个问题的。

## 为什么校外访问不了

学校购买的数据库、软件授权等服务，通常按"校内 IP 范围"来授权。IP 地址可以理解为你的设备在网络上的临时门牌号。也就是说，只有从校园网内部的 IP 地址访问，数据库才会认为"你是学校的人"，然后让你使用。

你在家里、在咖啡馆、在火车上，用的都是运营商或公共 Wi-Fi 的网络，IP 地址不在学校购买的范围内，所以数据库会拒绝访问。

注意：这和"你有没有学校账号"不是一回事。即使你知道自己的统一身份认证账号密码，校外直接访问图书馆数据库时，数据库并不认识这个账号——它只认你来自哪个网络。

## 常见的三种校外访问方案

学校解决这个问题的方式，通常在这三种之中。你的学校可能只支持其中一种或两种，搞清楚自己学校支持哪种就行。

### WEBVPN

**这是什么**

WEBVPN 是一个网页入口。你在浏览器里打开学校提供的 WEBVPN 网址，用统一身份认证登录后，再通过它访问图书馆数据库等校内资源。你的浏览器流量会经过学校的服务器，所以数据库看到的是学校校内的 IP 地址。

**特点**

- 不需要安装客户端，有浏览器就能用。
- 只转发网页流量，其他网络应用不会走学校网络。
- 访问速度取决于学校服务器的处理能力和网络带宽。

**适合场景**

- 偶尔查资料、看论文。
- 在公用电脑上临时访问校内资源。

### VPN 客户端

**这是什么**

VPN 客户端是一种需要下载安装的软件。连接后，你电脑上的网络流量通常会先经过学校的服务器，再从学校网络出去。数据库看到的也是学校校内的 IP 地址。

**特点**

- 安装后全局生效，不仅浏览器，其他软件也可以通过 VPN 访问校内资源。
- 连接期间，你的网络流量大多会经过学校，访问国内网站可能会变慢，访问国外网站可能会变快或变慢，取决于学校的网络出口。有些学校的 VPN 只有访问校内资源时才走学校网络，其他流量不受影响。
- 部分学校对 VPN 客户端的同时在线人数有限制。

**适合场景**

- 需要频繁、稳定地访问校内资源。
- 需要使用某些只能在校内网络激活的正版软件。

**不用时记得断开**

因为 VPN 会把大量流量导向学校，不看校内资源时建议断开，以免影响访问其他网站的速度。

### CARSI

**这是什么**

CARSI 是一种"无感知"的校外访问方式。你在数据库官网直接点击"机构登录"或"通过机构访问"，选择自己的学校，然后用统一身份认证登录。之后数据库就知道你是学校的人，直接给你开放访问权限。

**特点**

- 不需要安装客户端，也不需要每次先打开某个入口网页。
- 只在访问特定数据库时生效，不会影响其他网络流量。
- 不是所有学校、不是所有数据库都支持 CARSI，要看学校和数据库有没有接入。

**适合场景**

- 学校已经接入 CARSI，且你常用的数据库支持 CARSI。
- 只想快速查一篇论文，不想开 VPN。

## 怎么判断自己学校用哪种方案

最直接的方法：

1. 打开学校图书馆网站或 IT 部门网站。
2. 查找"校外访问""数据库校外访问""VPN""CARSI""WEBVPN"等关键词。
3. 看网站给出的说明和入口链接。

如果找不到，可以：

- 在搜索引擎里搜"你的学校名 + 校外访问/VPN/CARSI/WEBVPN"。
- 问图书馆咨询台或 IT 部门。
- 问学长学姐："你们在家怎么查图书馆数据库？"

## 你可能会遇到的问题

### 连了 VPN 还是打不开数据库

- 确认 VPN 是否已经成功连接。有些客户端需要登录后还要手动点击"连接"。
- 确认访问的数据库网址是否正确。有些数据库有多个入口，只有特定入口支持校外访问。
- 清除浏览器缓存（在浏览器设置里搜索"清除缓存"就能找到）或换浏览器试试。
- 部分数据库可能不支持通过 VPN 访问，如果学校提供其他校外访问方式，可以换 WEBVPN 或 CARSI 试试。

### WEBVPN 页面打不开

- 确认网址是否正确。学校可能会更换 WEBVPN 域名。
- 用学校网络使用指南里提供的 IP 地址或备用域名试试。
- 换个浏览器或清除浏览器缓存（在浏览器设置里搜索"清除缓存"就能找到）。

### CARSI 登录后数据库仍不让访问

- 不是所有数据库都接入了 CARSI。如果学校支持，可以换 WEBVPN 或 VPN 客户端试试。
- 有些数据库的 CARSI 入口隐藏得比较深，通常在登录页面的"机构登录""通过机构访问""Institutional Access"等位置。

### 访问速度很慢

- 校外访问的速度受学校服务器负载、网络带宽、你的本地网络质量等因素影响，慢是常见的。
- 如果学校支持多种校外访问方式，可以都试试，看哪种在自己当前网络环境下更快。一般来说，CARSI 通常比 WEBVPN/VPN 快一些，但具体要看学校和数据库的配置。

## 你的行动项

1. **搞清楚学校支持哪些校外访问方式**——去图书馆网站或 IT 部门网站查一下，通常会有专门的校外访问说明页面。
2. **如果学校有 WEBVPN 或 VPN 入口，收藏到浏览器书签**——方便下次直接打开。不知道怎么收藏的话，可以搜索"浏览器怎么添加书签"。
3. **测试一种方式能否正常使用**——在家或校外网络环境下，试着打开一个图书馆数据库，确认流程走通了。

如果在配置 VPN 客户端或登录校外访问系统时遇到看不懂的选项，先停下来，问 IT 部门或学长学姐，不要急着下载来历不明的客户端或填写敏感信息。
