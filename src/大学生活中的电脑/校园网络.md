# 校园网络

> 阅读前提：建议先阅读[《开篇：大学里的数字世界》](./开篇：大学里的数字世界.md)中“大学里有一套数字基础设施”一节，了解校园网在大学数字体系中的位置。如需了解更多网络基础知识，可参考[《理解你的网络》](../主要内容/理解你的网络.md)。

前面提到，大学的数字基础设施有三件事：网络、资源、服务。网络是基础——没网很多事都干不了。这一节专门讲校园网。

## 这是什么

校园网就是学校部署的局域网络，覆盖教室、宿舍、图书馆等校园区域。你用它上网、访问校内资源、使用学校提供的各类服务。

和家里的 Wi-Fi 最大的区别是：**校园网需要认证才能使用**。不是连上就能用，而是连上之后还需要额外的身份验证。

## 为什么需要认证

家里装 Wi-Fi，设个密码就行——知道密码的人都能连。学校不一样，校园网覆盖范围大、使用人数多，认证的核心目的有三个：

- **计费**：部分学校按流量或时长收费，需要记录谁用了多少。
- **管理**：控制同时在线设备数量，防止一个人占太多资源。
- **追溯**：网络出问题或有人违规使用时，能追溯到具体账号。

换句话说，认证不是学校故意为难你，而是管理大规模网络的必要手段。

## 两种常见的认证方式

校园网认证主要有两种模式，搞清楚你学校用的是哪种，很多问题就能迎刃而解。

### Portal 认证

这是最常见的方式。连上 Wi-Fi 后，浏览器会自动跳转到一个登录页面，在页面上输入账号密码，通过后才能正常上网。

原理：你的设备连上 Wi-Fi 后，学校会先临时分配一个网络地址（可以理解为你的设备在校内网络里的“临时门牌号”），但学校的网关设备会拦截所有网络请求，强制跳转到认证页面。认证通过后，网关才放行你的流量。

这个过程意味着：**“连上了 Wi-Fi”和“通过了认证”是两回事。** 你可能看到 Wi-Fi 图标显示已连接，但浏览器打不开任何网页——这不是断网了，是还没通过认证。

### 802.1X 认证

这种方式不需要打开浏览器。你在电脑的网络设置里输入账号密码，连接 Wi-Fi 时就自动完成认证。认证过程在后台进行，不会弹出任何页面。

这种方式的好处是不会出现“连上了但上不了”的情况，认证在连接阶段就完成了。但它的配置相对复杂，部分学校会在迎新期间提供配置教程。

### 怎么判断你学校是哪种

- 连上 Wi-Fi 后打开浏览器，看会不会自动跳到一个登录页面——会的话是 Portal 认证。
- 如果连上后直接能上网，或者需要在网络设置里填写账号密码——这是 802.1X 认证。
- 查学校的网络使用指南，通常会明确说明认证方式。

## 你可能会遇到的问题

### 认证页面弹不出来

Portal 认证最常见的问题。连上 Wi-Fi 后浏览器没自动跳转，直接打开网页也没反应。

这通常不是你的问题——认证系统的触发方式有时比较特殊。可以尝试：

- **手动输入认证页面地址**：学校通常会在网络使用指南里提供认证页面的校内 IP 地址，在浏览器地址栏直接输入这个地址就能打开认证页面。问学长学姐，他们大概率也遇到过这个问题。
- **检查系统代理**：代理是一种把网络流量转接到其他服务器的设置，如果你开了代理软件或 VPN（虚拟专用网络）类工具，它可能干扰认证页面的跳转。暂时关闭代理再试试。
- **换无痕模式或换浏览器**：有时浏览器缓存或扩展程序会阻止跳转。
- **忘记网络后重新连接**：断开 Wi-Fi 再重新连接，有时能触发认证页面。

### 收费与额度

各校收费方式不同：有的不收费，有的按月收费，有的给免费额度超出后收费，有的分时段免费。如果学校收费，搞清楚计费周期和额度，避免月底突然断网。

如果校园网不方便或临时断了，手机热点是常用的备用方案。用 USB 数据线连接手机和电脑做网络共享，比开 Wi-Fi 热点更稳定、更省电。

### 多设备限制

很多校园网限制同时在线的设备数量（通常 2–3 台）。认证通过后，学校网关会记录你的设备。如果名额满了，新设备认证时旧设备会被挤下线。

如果你发现一台设备连上后另一台自动掉线，大概率是到了设备数量上限。解决办法：在不需要的设备上“忘记校园网”或断开连接，给新设备腾出位置。

### 宿舍接路由器

有些同学会在宿舍接路由器——路由器对外只占一个设备名额，对内可以接多台设备。但需要注意：

- 不是所有学校都允许接路由器，有些学校会检测并限制。具体看学校的网络管理规定。
- 如果学校允许，按说明书配置即可。如果学校不允许，不建议强行接——可能会被限速或限制使用。

大多数情况下，宿舍的 Wi-Fi 信号已经够用，不需要额外接路由器。如果确实信号不好，可以先联系学校 IT 部门反映情况。

### 网速慢

校园网是共享带宽——整栋楼甚至整个校区共用一条出口线路。用网高峰期（晚上、周末）网速可能明显下降，这是资源竞争造成的，不是你的电脑有问题。

如果需要稳定网速（视频会议、在线考试、提交作业），可以避开高峰时段，或用手机热点应急。如果宿舍有有线网口，用网线直连通常比 Wi-Fi 更稳定。

### 宿舍有线网络

宿舍里通常有墙面网口，可以用网线直接连接电脑。网线接口是方形的（比电话线接口大，叫 RJ45 接口），普通笔记本电脑和台式机都有这个接口。有线连接比 Wi-Fi 更稳定，延迟更低——对网络延迟敏感的应用（如视频会议、在线考试、实时协作）用有线更稳。

需要注意的几点：

- 宿舍网口数量有限，不过大部分情况下够用——大家更多用 Wi-Fi，有线只是更稳定的备选方案。
- 网线需要自己准备，买一根合适长度的即可。网线有不同的规格，包装上会标注，普通的 CAT5e 或 CAT6（两种常见的网线规格，数字越大通常支持越快）都能用。
- 有些学校的网口也需要认证，和 Wi-Fi 认证可能是同一套账号，也可能不是。

## 你的行动项

拿到校园网账号后，你可以：

1. **找到你的学校是哪种认证方式**：Portal 还是 802.1X。搜索“学校名 + 校园网认证”，或查看 IT 部门网站的网络使用指南。
2. **搞清楚收费规则**：免费还是付费？按流量还是按时间？额度多少？
3. **记住认证页面地址**（如果是 Portal 认证）：把它保存到浏览器书签，认证页面弹不出来时直接访问。
4. **确认设备数量限制**：同时能连几台设备，合理管理。
5. **准备一根网线**：宿舍有线网络通常更稳定。

遇到问题时，先查学校的网络使用指南，不行再联系 IT 部门或问学长学姐。如果看到路由器、交换机、IP 地址这些概念不太明白，也不用急着折腾设备——先把能上网的问题解决，其他的以后慢慢了解。
