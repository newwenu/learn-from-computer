# 编程课与远程工具

> 阅读前提：这一节主要面向有编程课、实验课或需要远程操作服务器的学生。如果你没有这些课程，可以跳过。如需了解命令行基础知识，可参考[《命令行入门》](../命令行知识/命令行入门.md)。

很多专业都会学一点编程——不只是计算机专业，理工科甚至部分文科专业也会开设编程课程。写代码和日常用电脑有很多不同：你需要安装开发环境、理解代码文件、学会看报错信息，有时还需要远程连接实验室的服务器。

这一节讲编程入门时需要注意的几个关键点，以及远程操作服务器的基本概念。

## 编程课程

### 写代码不是打开软件就能开始

日常软件通常是“打开就用”，但写代码需要先搭建“开发环境”。开发环境通常包括：

- **编辑器或 IDE（集成开发环境）**：用来写代码的工具，比如 Visual Studio Code、PyCharm、IntelliJ IDEA。
- **编译器或解释器**：把代码转换成计算机能执行程序的工具。不同语言需要不同的编译器或解释器。
- **运行时环境**：有些程序运行时需要额外的支持库或环境。

课程通常会指定使用什么工具，按老师要求安装即可。如果课程没有指定，问学长学姐最可靠——同一门课他们往往已经踩过坑。

### 不同语言需要不同的环境

- **C/C++**：需要安装编译器（如 MinGW、GCC），配合 IDE 使用。
- **Java**：需要安装 JDK（Java 开发工具包）。
- **Python**：需要安装 Python 解释器。
- **Web 前端**：主要需要浏览器和编辑器，不需要额外安装编译器。

### 环境配置是第一个坎

很多初学者卡在安装环境这一步：下载地址找不到、安装路径不对、环境变量没配置好。这很正常，不是你的问题。

遇到问题时：

- 仔细看报错信息，通常第一行或最后一行会指出问题所在。
- 把报错信息复制到搜索引擎，加上语言名称搜索，大概率有人遇到过同样的问题。
- 问同学或助教，环境配置是编程入门阶段最常见的问题。

### 代码文件是纯文本文件

代码文件的扩展名通常是 `.c`、`.java`、`.py`、`.html` 等。它们本质上是纯文本文件，可以用记事本打开，但用专门的编辑器写代码更方便，因为有语法高亮、自动补全和错误提示。

**不要用 Word 写代码**。Word 保存的文件不是纯文本格式，编译器无法正确读取。

### 编译执行和解释执行

不同编程语言的运行方式不同：

- **编译型语言（如 C/C++、Java）**：需要先通过编译器把代码转换成可执行文件，再运行。如果代码有语法错误，编译阶段就会报错。
- **解释型语言（如 Python）**：直接运行代码文件，解释器逐行执行。语法错误通常在运行到那一行时才会报错。

### 写代码的习惯

- **改一点测一点**：不要一次改一大堆代码再运行，出了问题很难定位。
- **注意保存**：很多编辑器有自动保存功能，可以开启。
- **备份重要代码**：可以用云盘同步代码文件夹，换电脑也能继续写。

### 版本管理

写代码时经常会改很多版，想回到之前的版本怎么办？最简单的做法是每次大改前复制一份备份。更专业的做法是用 Git——一个版本管理工具，可以记录每次修改，随时回退。

课程可能不会教 Git，但如果你打算长期写代码，花点时间学会它会省很多麻烦。GitHub（一个代码托管平台）学生包可以免费使用很多开发工具。

## 远程连接与服务器

### 什么是远程连接

远程连接就是从你的电脑通过网络操作另一台电脑（通常是服务器）。你在这边输入命令或操作界面，实际执行是在远端的服务器上，结果再传回你的屏幕。

常见的远程连接方式有两种：

- **SSH（Secure Shell，安全外壳协议）**：通过命令行连接，适合执行命令、运行程序。
- **远程桌面**：通过图形界面连接，像操作自己的电脑一样操作服务器。

### 为什么需要远程操作服务器

部分专业（尤其是理工科和研究生）会用到实验室或课题组的服务器：

- 服务器性能比个人电脑强，适合跑计算量大的程序。
- 服务器上可能预装了你需要的软件和环境。
- 有些实验需要持续运行，不能关机，放在服务器上更稳定。

### 从校外连接通常需要先连 VPN

实验室服务器通常部署在校园内网。如果你在宿舍或校园内，一般可以直接连接；如果你在校外，可能需要先通过 VPN 进入校园网，再用 SSH 或远程桌面连接服务器。

### 具体配置由谁指导

远程连接服务器的具体配置因实验室而异，通常由实验室的师兄师姐或导师指导。这里先了解基本概念即可：需要知道服务器的 IP 地址、用户名、密码，以及用 SSH 还是远程桌面连接。

## 你的行动项

1. **按课程要求安装开发环境**，不要自己随意选择工具版本。
2. **遇到环境配置问题先搜索报错信息**，这是最高效的解决方式。
3. **写代码时养成保存和备份的习惯**。
4. **如果需要远程连接服务器**，向实验室师兄师姐或导师索取连接方式和注意事项。

如果安装环境时遇到完全看不懂的报错，不要反复尝试卸载重装，先截图或复制报错信息去问懂的人。
