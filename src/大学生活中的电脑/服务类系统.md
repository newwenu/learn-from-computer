# 服务类系统

> 阅读前提：建议先阅读[《开篇：大学里的数字世界》](./开篇：大学里的数字世界.md)了解大学数字基础设施的整体框架，以及[《统一身份认证》](./统一身份认证.md)了解学校账号的使用方式。

大学里有很多事务不再需要跑到各个办公室办理，而是搬到了线上。请假、报修、缴费、证明开具、查课表、查成绩……这些功能通常集中在学校的“网上办事大厅”或“一站式服务平台”里。

这一节讲这类系统常见入口有哪些、能办哪些事，以及怎么找到自己学校的入口。

## 这是什么

服务类系统是学校把各类行政事务搬到线上后形成的平台。通过这个系统，你可以在线完成很多原本需要线下跑腿的流程。

常见功能包括：

- **请假**：在线提交请假申请，等待辅导员或老师审批。
- **报修**：宿舍或教室设施损坏时，在线提交报修工单。
- **缴费**：学费、住宿费、电费等在线缴纳。
- **证明开具**：在读证明、学籍证明、成绩单等在线申请。
- **课表查询**：查看本学期课程安排。
- **成绩查询**：查看各科成绩和绩点。
- **奖学金、助学金、评优申请**：部分学校也通过这些系统处理。

## 为什么各校入口差异大

不同学校使用的系统可能完全不同：有的学校用自建平台，有的采购第三方系统，有的集成在企业微信或钉钉里。这是因为：

- 学校信息化起步时间不同，积累的系统也不同。
- 各校管理流程不同，系统需要匹配本校的审批链条。
- 采购和开发决策由学校各自做出，没有全国统一的平台。

所以这一节不讲具体操作步骤，只讲入口类型和查找方法。你需要根据自己学校的情况去找对应的入口。

## 常见的入口类型

### 学校网站上的办事大厅

很多学校会在官网首页设置“网上办事大厅”“师生服务中心”“一站式服务”等入口。点进去后通常需要用统一身份认证登录。

### 企业微信 / 钉钉工作台

如果学校用企业微信或钉钉作为官方沟通工具，办事入口通常集成在工作台里。打开应用后，在“工作台”或“应用”页面可以找到请假、报修、查成绩等功能。

### 学校官方应用

部分学校有自己的官方应用，里面整合了课表、成绩、缴费、报修等功能。

### 学校公众号

学校公众号的菜单里有时会链接到办事大厅或常用功能页面，适合临时使用。

## 登录方式

这类系统通常通过**统一身份认证**登录。也就是说，你用一个账号密码就能进入大多数服务页面。如果登录时遇到跳转问题，可以参考[《统一身份认证》](./统一身份认证.md)中“你可能会遇到的问题”部分。

## 你可能会遇到的情况

### 找不到入口

如果不知道学校的办事入口在哪，可以尝试：

- 搜索“学校名 + 网上办事大厅 / 一站式服务 / 师生服务中心”。
- 查看学校官网首页的导航栏或底部链接。
- 问辅导员或学长学姐：“我们学校请假/报修/查成绩在哪弄？”

### 流程卡住

在线流程通常需要多级审批，比如请假要经过辅导员、学院、学校等不同环节。如果流程长时间没动静，可以查看当前审批到了哪一步，必要时联系对应的审批人。

### 功能位置经常变化

学校可能会调整系统界面或迁移到新平台。如果之前常用的功能找不到了，可以去学校 IT 部门网站或公众号查看最新的使用指南。

## 你的行动项

1. **找到学校服务类系统的入口**——通过官网、企业微信/钉钉、官方应用或公众号。
2. **登录一次确认账号能用**——通常用统一身份认证登录。
3. **收藏常用的功能页面**——如请假、报修、查成绩、查课表等。
4. **了解常用流程需要谁审批**——避免提交后不知道找谁跟进。

如果你在查找入口或提交申请时遇到不确定的选项，先不要急着提交，可以问辅导员或学校 IT 部门。
